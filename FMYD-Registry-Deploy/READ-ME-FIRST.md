# FMYD ICT Registry — Easy Setup Instructions

**Federal Ministry of Youth Development | ICT Department**

---

## 🚀 How to Run (Zero Setup Required!)

**No database installation, no passwords, and no command line needed.**

1. **Extract the ZIP folder** onto your PC (e.g., `C:\FMYD-Registry\` or Desktop).
2. Double-click **`FMYD-ICT-Registry.exe`** (or `SETUP.bat` to create a Desktop shortcut).
3. The official registry desktop window opens immediately!

## ☁️ Google Drive Automatic Cloud Backup (Optional)

The app can automatically back up the database and uploaded scans to Google Drive:

1. Right-click the **FMYD Emblem icon** in the system tray (bottom-right of your Windows taskbar).
2. Click **"Setup Google Drive Backup"**.
3. Sign in to your designated Google account in the browser that opens.
4. Done! It will automatically back up every hour.
